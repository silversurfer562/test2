# Log

A lab notebook, not a journal. One file per week: `week-NN.md`, from
`templates/weekly-review.md`.

Rubric scores go in `rubric-week-00.md`, `rubric-week-06.md`,
`rubric-week-12.md` — same instrument all three times, or the comparison
means nothing.

`rubric-week-00.md` has a head start: `docs/baseline-week-00.md` scores it
from repo evidence. Correct it. It is a read of one repo at one commit and it
cannot see work you never pushed.

## The one rule

**Write the prediction before you run the eval.**

> I expect the pipeline version to lose on quality by ~5 points and win on
> cost by 3x.

Then the result. Then the gap.

The gap is where the learning is. Numbers recorded after the fact only tell
you what happened; a prediction recorded before tells you what you believed,
which is the thing that needs correcting. It also makes it impossible to
quietly remember having expected the result you got.
